# 🐍 Basic Python Programming

A collection of beginner-friendly Python programs covering the fundamentals of Python programming. This repository is ideal for students and anyone starting their Python learning journey.

## 📚 Topics

- Variables & Data Types
- Operators
- Conditional Statements
- Loops
- Functions
- Lists, Tuples, Dictionaries & Sets
- Strings
- File Handling
- Exception Handling
- Basic OOP
- Practice Programs

## 🚀 Getting Started

```bash
git clone https://github.com/MhdRoshanp/basic-python.git
cd basic-python
python filename.py
```
